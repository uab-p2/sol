    Herencia

    La herencia es...

    • reutilización de atributos/métodos en la clase base
    • Constructors aren't inherited automatically — Derived must call each base's constructor explicitly
    • referencias de la clase base para manejo de objetos de las clases derivadas
    • : public A vs : A

    • métodos virtuales y polimorfismo -> actually split polymorphism to its own section

    • access to parent methods A::f() other.Z::g()

    multiple inheritance: - Each base class access specifier (public, protected, private) controls how that base's members are exposed in Derived. - If two bases have members with the same name, you must disambiguate: d.Base1::foo(); in its init list if they need arguments:

    Orden¶

    En este proyecto usamos el siguiente orden de declaración e implementación de miembros en los ficheros .h y .cpp:

    1. Parte pública:

      1. Constructores.
      2. Destructores.
      3. Métodos públicos interfaz principal.
      4. Getters y setters.
      5. Operadores sobrecargados.
      6. Constantes públicas.

    2. Parte protegida/privada:

      1. Métodos protegidos/privados.
      2. Constantes protegidas/privadas.
      3. Atributos protegidos/privados.

#include <string>

///
/// Hot and spherical object in space.
///
class Star {
public:
    /// By default, create Earth's sun
    Star();

    /// Create a custom star given its wavelength
    /// @param name star name
    /// @param x,y,z position relative to Earth's sun.
    /// @param wavelength maximum emission wavelength in nm
    Star(const std::string& name, double x, double y, double z, double wavelength);

    /// Create a custom star given its type
    /// @param name star name
    /// @param x,y,z position relative to Earth's sun.
    /// @param type one of the possible valid types (see set_type)
    Star(const std::string& name, double x, double y, double z,
         const std::string& type);

    /// @param other the other star to get the distance to
    /// @return the distance between this and the other star, in light years
    double distance(const Star& other) const;

    /// @return the type name based on the wavelength, or "other"
    std::string get_type() const;
    /// Set the star type. The maximum wavelength is automatically derived from
    /// it.
    /// @param type must be one of "blue", "yellow", "red", "brown".
    ///   Otherwise, it is ignored.
    void set_type(const std::string& type);

    /// @return the current star name
    std::string get_name() const { return m_name; }
    /// @param name new star name. If it is shorter than a minimum,
    /// "0" is appended until it isn't.
    void set_name(const std::string& name);

    /// @param x,y,z variables where the current star's position is saved.
    void get_position(double& x, double& y, double& z) const;
    /// @param x,y,z the position relative to the Earth's sun, in light years
    void set_position(double x, double y, double z);

    /// @return the star wavelength
    double get_wavelength() const { return m_wavelength; }

protected:
    /// Minimum name length.
    const unsigned MIN_NAME_LENGTH = 5;

    /// Scientific or familiar name. Can include numbers (at least 5 characters).
    std::string m_name;
    /// Position relative to Earth's sun (facing front), in light years.
    double m_x, m_y, m_z;
    /// Maximum emission wavelength in nm.
    double m_wavelength;
};

    Atributos, getters y setters

    Atributos¶

    En este proyecto, declaramos todos los atributos protected: o private:.

    Sólo el código de nuestra clase tiene la responsabilidad de mantener estados válidos; el resto de clases no puede modificar este estado directamente.

    Getters¶

    Para cada atributo podemos crear un getter, un método público que devuelve el valor de ese atributo.

    • Su nombre comienza por get_ (o is_ si el atributo es bool), seguido del nombre del atributo sin m_.

    • Retorna el tipo de dato del atributo.

      • Si el atributo es de un tipo básico, el retorno es de ese mismo tipo.

      • Si el tipo de un atributo es una clase, el retorno puede ser una copia o una referencia al propio atributo.

    • No acepta argumentos.

    • Es un método const; no altera el estado del objeto durante la consulta.

    Setter¶

    Independientemente del getter, podemos crear setters para nuestros atributos.

    • Su nombre comienza por set_, seguido del nombre del atributo sin m_.
    • No retorna nada (void).

    • Toma un argumento, cuyo tipo depende del del atributo.

      • Si el atributo es de un tipo básico, el argumento del setter es ese mismo tipo.

      • Si el tipo de un atributo es una clase, el argumento del setter es una referencia const.

    • No es un método const.

    • Puede validar, modificar o rechazar el cambio para preservar la lógica (ver set_chalks debajo).

    Getters

    Para cada atributo podemos crear un getter, un método público que devuelve el valor de ese atributo.

    • Su nombre comienza por get_ (o is_ si el atributo es bool), seguido del nombre del atributo sin m_.

    • Retorna el tipo de dato del atributo.

      • Si el atributo es de un tipo básico, el retorno es de ese mismo tipo.

      • Si el tipo de un atributo es una clase, el retorno puede ser una copia o una referencia al propio atributo.

    • No acepta argumentos.

    • Es un método const; no altera el estado del objeto durante la consulta.

    Setter

    Independientemente del getter, podemos crear setters para nuestros atributos.

    • Su nombre comienza por set_, seguido del nombre del atributo sin m_.
    • No retorna nada (void).

    • Toma un argumento, cuyo tipo depende del del atributo.

      • Si el atributo es de un tipo básico, el argumento del setter es ese mismo tipo.

      • Si el tipo de un atributo es una clase, el argumento del setter es una referencia const.

    • No es un método const.

    • Puede validar, modificar o rechazar el cambio para preservar la lógica (ver set_chalks debajo).
