    Silicio y titanio¶

    Tiempo estimado: 30min

    Tu primera misión es configurar un buen entorno de desarrollo que te sirva para todo el proyecto. Te proponemos una prueba de humo para tu nuevo sistema: compilar el código tu primer quest del proyecto SOL.

    Objetivo
    • Configura tu entorno de desarrollo y compila el código del quest.

    Plataforma de desarrollo¶

    Questions

    • Elige tu(s) sistema(s) operativo(s) y sigue las instrucciones para instalar tu plataforma de desarrollo: Plataforma de desarrollo.

    Código del proyecto SOL¶

    Questions

    • Consigue el código completo del proyecto SOL de cualquiera de las maneras propuestas: Clonación/descarga del proyecto SOL. A continuación, cierra tu entorno de desarrollo (IDE).

    Quest 'Silicio y titanio'¶

    Questions

    • Sigue las instrucciones en Apertura de un quest en el IDE para abrir este quest (silicio_y_titanio) en tu IDE.

    Paso 4/4: Prueba de humo¶

    Questions

    • Una prueba de humo consiste en enchufar un aparato nuevo o recién arreglado para comprobar si empieza a quemarse o si funciona bien. Te proponemos una prueba de humo para tu nuevo y flamante plataforma de desarrollo: compilar y ejecutar el código de este quest (silicio_y_titanio).

    • Siguiendo las instrucciones en Compilación y ejecución de un quest, podrás ver un mensaje indicando cómo se compara la velocidad de tu máquina con la de la mía. ¿Cuál de las dos nos lleva más rápido?
