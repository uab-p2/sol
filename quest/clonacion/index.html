    Clonación¶

    Duración prevista: 1h

    Como es habitual en cualquier instalación científica en 3026, la estación SOL dispone de un laboratorio de clonación, pero también les está comenzando a fallar. Estamos prototipando unos androides autoclonables que puedan usar. ¿Nos echas un cable?

    Objetivos
    • Implementa y distingue constructores, constructores copia y operadores asignación.
    • Practica las interacciones entre composición y constructores.
    • Utiliza copias y referencias de instancias std::vector.

    Clonación¶

    Además de lo anterior, queremos poder "clonar" los objetos de tipo Android para que puedan multiplicarse una vez en la estación SOL. Los requisitos de esta parte son:

    1. Nombre y generación.
      El clon mantiene el nombre de modelo del original, pero incrementa su número de generación en 1.

    2. Registro de órdenes.
      El clon no recuerda las órdenes que realizó el original (por privacidad), pero registra "original had N" como su primera instrucción recibida, donde N es el número de órdenes que ha recibido el original en el momento de la clonación.

    3. Construcción por copia y asignación.
      Queremos poder usar tanto la sintaxis A como la sintaxis B para realizar las "clonaciones" (hay dos versiones de la sintaxis A).

#include "android.h"
using namespace std;

int main() {
    Android original("panda");
    original.command("you are the original");

    // Syntax A
    Android copy1(original);
    Android copy2 = original;

    copy1.command("you are copy 1");
    copy2.command("you are copy 2");

    // Syntax B
    copy2 = original;
    copy2.command("you are still copy 2");

    return 0;
}

    #include <iostream>
#include <vector>
#include "android.h"
using namespace std;

void process(vector<Android> batch) {
    cout << "Processing " << batch.size() << " androids..." << endl;
}

int main() {
    Android original("giskard");
    original.command("stay still");

    std::vector<Android> batch;
    batch.push_back(original);

    process(batch);
    cout << "Processing finished." << endl;

    return 0;
}
