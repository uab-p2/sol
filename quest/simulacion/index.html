    Simulación¶

    Duración prevista: 1h

    Antes de cualquier actuación en el espacio, la tripulación realiza simulaciones de todas las naves involucradas. Esta vez el sistema les funciona, pero no es compatible con nuestras naves. Preparémosles un nuevo sistema de simulación que funcione con cualquier tipo de nave.

    Objetivos
    • Utiliza herencia para especializar clases de objetos.
    • Diseña jerarquías de clases.
    • Usa la clase base para manejar las especializaciones.

    #pragma once

/// Abstract ship for simulations, base of all implemented models.
class Ship {
public:
    /// Needed because virtual methods are defined.
    virtual ~Ship();

    /// Get the current position of the ship, expressed in meters.
    /// @param x,y,z variables where the ship's position is saved.
    void get_position(double& x, double& y, double& z) const;

    /// @return true if and only if the health and the battery
    ///   are strictly above zero.
    virtual bool is_working() const;

    /// Attempt to move the ship to the destination (x,y,z).
    /// The base Ship class simply changes position without
    /// affecting the battery charge. Subclasses may modify this behavior.
    /// @param x,y,z destination
    /// @return true if the ship moved to the destination
    ///   (potentially using battery charge), or false
    ///   if the ship could not move to the destination
    ///   (e.g., no fuel, no health, it's a fixed station...).
    virtual bool move(double x, double y, double z);

protected:
    /// Create a ship with the specified battery charge and position.
    Ship(double battery_charge, double x=0, double y=0, double z=0);

    /// @return the distance from the current position to (x,y,z), in distance units.
    double distance_to(double x, double y, double z) const;

    /// Ship position with respect to some reference point.
    double m_x, m_y, m_z;

    /// Current battery charge.
    double m_battery;
};

    #include "ship.h"

#include <cmath>

Ship::~Ship() {
}

Ship::Ship(double battery_charge,
           double x, double y, double z)
    : m_x(x), m_y(y), m_z(z), m_battery(battery_charge) {
    // Executed *after* direct initialization
    if (m_battery < 0) {
        m_battery = 0;
    }
}

void Ship::get_position(double& x, double& y, double& z) const {
    x = m_x;
    y = m_y;
    z = m_z;
}

bool Ship::is_working() const {
    return m_battery > 0;
}

bool Ship::move(double x, double y, double z) {
    m_x = x;
    m_y = y;
    m_z = z;
    return true;
}

double Ship::distance_to(double x, double y, double z) const {
    double dx = m_x - x;
    double dy = m_y - y;
    double dz = m_z - z;
    return std::sqrt(dx * dx + dy * dy + dz * dz);
}

    /// Person transportation ship
class Transport : public Ship {
public:
    /// Create a transport ship with `passengers` passengers inside.
    /// @param passengers: the initial number of passengers in the ship.
    /// @param x,y,z: position where the transport is created.
    Transport(unsigned passengers,
              double x = 0, double y = 0, double z = 0);

    /// @return the current number of passengers
    unsigned get_passenger_count() const;

    /// @return the maximum number of passengers
    ///   this ship can carry.
    virtual unsigned get_maximum_passage() const;

    /// Attempt to board more people onto the ship, but only
    /// if they all fit.
    /// @param passengers the number of passengers that are
    ///   (or aren't) loaded onto the ship.
    /// @return true if the passengers boarded, false if there
    ///   was not enough room, and no one boarded.
    virtual bool load_passengers(unsigned passengers);

    /// Attempt to disembark the requested number of passengers,
    /// but only if enough passengers are onboard. Otherwise,
    /// the transport contents are not changed.
    /// @param passengers the number of passengers to disembark.
    virtual bool unload_passengers(unsigned passengers);

    /// Attempt to move the Transport ship to (x,y,z).
    /// There must be enough battery (at least the cost reported by `move_cost`)
    /// or the move is not performed at all (and no battery is spent).
    /// @return true if the ship moved and consumed the battery. false if
    ///   the ship did not move nor spend any battery.
    bool move(double x, double y, double z) override;

protected:
    /// @return the amount of battery needed to go from the current position to (x,y,z).
    ///   The cost is 10 + distance * passengers * cost_per_person_per_distance.
    virtual double move_cost(
        double x, double y, double z,
        double cost_per_person_per_distance) const;

    /// Number of passengers onboard the transport ship.
    unsigned m_passengers;
};

    • ¿Podremos crear objetos tipo Transport directamente?

    • ¿Qué funcionalidad(es) de Ship hereda Transport?

    • ¿Qué funcionalidad(es) pueden diferir entre Ship y Transport?

    • Implementa el resto de la clase en transport.cpp considerando los requisitos documentados en transport.h (ver arriba) y también:

      1. Creación:

        • Los transportes se crean con 100 unidades de batería (battery)
        • Los transportes comienzan en \( \bar{v}_0 = (0,0,0) \) por defecto, aunque se puede especificar la posición inicial durante la creación.
        • Si se indica un número de personas a bordo inferior a 10, el número se aumenta a 10 (¡la tripulación es necesaria!).
        • Un objeto Transport no puede llevar más de 25000 personas a bordo: si se indica un número superior, se reduce a 25000.

      2. Embarque y desembarque.
        Un Transport ya creado también puede recoger más personas con load_passengers(n). Si caben las n personas adicionales sin superar el máximo de la nave, sube todo el mundo y el método devuelve true; si no caben, no sube nadie y devuelve false.

        Simétricamente, unload_passengers(n) desembarca personas: si pueden bajar las n personas indicadas sin dejar la nave por debajo de la tripulación mínima (10), baja todo el mundo y el método devuelve true; si no, no baja nadie y devuelve false.

      3. Movimiento.
        Una nave posicionada en \( \bar{v}_1 = (x_1,y_1,z_1) \) con destino \( \bar{v}_2 = (x_2,y_2,z_2) \) recorrerá la siguiente distancia, con el coste de batería asociado (sólo si tiene batería para el viaje completo - si no, no se moverá):

      $$ \text{distancia}(\bar{v}_1, \bar{v}_2) = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2 + (z_1-z_2)^2}, $$

      $$ \text{coste}(\text{distancia}, n_\text{personas}) = 10 + \text{distancia} \cdot \frac{n_\text{personas}}{250}. $$

    Una vez tengas Transport funcionando y probada localmente, crea también un transporte ligero LightTransport como especialización de Transport.

    class Station {
public:
    /// Place a station at (x,y,z) with the given number of passengers.
    Station(double x, double y, double z, unsigned passengers);

    /// Move as many passengers from this station to the destination station
    /// using the given transport. The transport must be able to move to
    /// this station location, load the passengers and then move to the destination.
    /// If any of these three steps fails, the next ones are not executed.
    /// @param transport transport to use (and modify).
    /// @param destination destination station.
    /// @return whether all three steps succeeded.
    bool send_passengers(Transport& transport, Station& destination);

    /// @return the current number of passengers in the station
    unsigned get_passengers() const;

    /// Get the position of the station in space
    /// @param x,y,z: variables where the x,y,z position is stored.
    void get_position(double& x, double& y, double& z) const;

protected:
    /// Position in space.
    double m_x, m_y, m_z;

    /// Number of passengers in the station
    unsigned m_passengers;
};

    #include <iostream>
#include <ostream>
#include <vector>
#include "transport.h"
#include "light_transport.h"
#include "station.h"
using namespace std;

void print_populations(
    Station& a, Station& b, Station& c, Transport& t) {

    cout << "Population - A:" << a.get_passengers()
        << " B:" << b.get_passengers()
        << " C:" << c.get_passengers()
        << " Transport:" << t.get_passenger_count()
        << endl;
}

int main() {
    std::vector<Station> stations = {
        Station(0, 0, 0, 20),
        Station(30, 0, 0, 15),
        Station(15, 26, 0, 10),
    };

    LightTransport transport(10, 0, 0, 0);

    cout << "Initial state:" << endl;
    print_populations(stations[0], stations[1], stations[2], transport);

    cout << "Transport A -> B: "
        << (stations[0].send_passengers(transport, stations[1])
                ? "ok" : "failed") << endl;
    print_populations(stations[0], stations[1], stations[2], transport);

    cout << "Transport B -> C: "
        << (stations[1].send_passengers(transport, stations[2])
                ? "ok" : "failed") << endl;
    print_populations(stations[0], stations[1], stations[2], transport);

    return 0;
}
